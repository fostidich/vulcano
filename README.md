# Vulkan explorable 3D world

Run the application with the following command.

```sh
just run
```

## Controls

- **WASD**: move the player
- **Mouse**: rotate camera
- **Shift**: go down
- **Space**: go up
- **Control**: sprint
- **ESC**: unfocus
- **F**: toggle flight
- **G**: toggle collisions
- **H**: toggle hitboxes
