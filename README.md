# Vulkan explorable 3D world

Run the application with the following command.

```sh
just run
```

## Controls

- **WASD**: move the player
- **Mouse**: rotate camera
- **Space**: jump / go up
- **Shift**: sneak / go down
- **Control**: sprint
- **ESC**: unfocus
- **Z**: zoom
- **F**: toggle flight
- **C**: toggle collisions
- **H**: toggle hitboxes
- **I**: info/debug screen
- **Q**: quit

## Showcase scene

Use argument `showcase` to load debug scene.

```sh
just run showcase
```
